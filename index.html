📦 Como subir para o seu GitHub em 3 passos:

  1. Baixe o pacote swile_os_crm_supabase_github.zip entregue no chat.
  2. Rode o SQL ao lado no SQL Editor do seu projeto no Supabase.
  3. Faça git push origin main para o seu repositório GitHub — o GitHub Actions (.github/workflows/deploy.yml) publica o CRM automaticamente no GitHub Pages!
